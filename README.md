# Banesa Ime Mobile

Aplikacioni iOS/Android për Banesa Ime.

## Stack

- Expo
- React Native
- TypeScript

## Nisja lokale

```bash
npm install
npm start
```

Pastaj hape projektin me Expo Go ose emulator.

## Status

Baza e parë përmban:

- Home screen
- Results screen
- Bottom navigation
- PropertyCard reusable
- Theme fillestar sipas Stitch

Të dhënat janë mock vetëm për fazën e dizajnit. Hapi pasues është lidhja me API-n ekzistuese të Banesa Ime.
